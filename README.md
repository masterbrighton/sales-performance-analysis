1. Problem Statement
   The objective of this project is to analyze sales performance, customer behavior and category trends using SQL, Python and data visualization techniques.

2. Dataset Description
   Superstore sales dataset containing orders, customers, products, sales, profit and shipping information from 2015–2018.

3. SQL Analysis
   Total Sales
   Monthly Growth Trend
   Category Performance
   Top Customers
   Shipping Delay Analysis

4. Python Insights
   pandas groupby analysis
   revenue trends
   category comparisons
   customer analysis

5. Excel Dashboard
   Total Revenue
   Number of Orders
   Number of Customers
   Average Order Value
   Revenue Trend
   Category Performance
   Top Customer Analysis

6. Business Recommendations
   Focus marketing on highest-performing categories.
   Investigate causes of declining categories.
   Improve retention of top customers.
   Monitor seasonal sales fluctuations.
